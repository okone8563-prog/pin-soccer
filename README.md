# Pin Soccer — publish with GitHub Pages

This is the complete static website. It does not need a server or a build step.

## Files
Keep these four files together in the same folder:
- `index.html` — the game page
- `styles.css` — the visual design
- `game.js` — the game code
- `README.md` — these instructions

## Publish it using GitHub (computer or iPad)

1. Download the Pin Soccer website ZIP and unzip/extract it.
2. Sign in at https://github.com/.
3. Create a public repository named `pin-soccer`.
4. Upload the actual files `index.html`, `styles.css`, `game.js`, and `README.md` to the top level of the repository. Do not upload only the ZIP.
5. Commit the files.
6. Open the repository's **Settings** tab, then **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch **main** and folder **/(root)**, then press **Save**.
9. Wait a few minutes. GitHub will show the website address, usually `https://YOUR-USERNAME.github.io/pin-soccer/`.
10. Open that address in Safari to play and share the game.

## Updating the game later
Upload changed files to the same repository and commit them. GitHub Pages republishes the site automatically.

You do not need to buy a domain name.
